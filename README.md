# イニDAC 店舗レビューサイト

頭文字D THE ARCADE の設置店舗を検索し、筐体メンテナンスや店舗の総合評価を共有するファン向けサイトのプロジェクトです。

## できること
- 店舗一覧・店舗名/住所検索
- 国名の自由入力・国名/地域名による絞り込み
- 海外店舗は国名のみで登録可能（日本国内の店舗は都道府県が必須）
- 管理者メール `grgt1462@gmail.com` のみがサイト文言を編集・公開保存可能（Supabase設定が必要）
- 店舗追加フォーム
- Google Mapsリンク
- 店舗ごとのレビュー一覧と平均評価
- メンテナンス・店舗総合評価（良い/普通/少し悪い/悪い）
- 店内ランク・通信状況（サブ評価、5段階）
- コメントと訪問日の投稿
- ログイン/新規登録UI
- レスポンシブ表示（スマートフォン対応）

## 現状と重要な注意
初期状態では **デモモード** です。データと簡易プロフィールは利用中のブラウザの `localStorage` に保存され、他のユーザーや別の端末には共有されません。画面にあるサンプル店舗・レビューはレイアウト確認用の架空データです。

実際に無料公開し、複数の人がアカウントを作って同じ店舗・レビューを共有するには、Supabaseの無料枠などを使ったバックエンド設定が必要です。管理者だけのサイト文言編集もSupabase Authと `site_content` テーブルを使うため、`supabase/schema.sql` を実行してください。手順は `DEPLOY.md` と `supabase/schema.sql` を参照してください。

## ローカルで確認
1. `index.html` をブラウザで開く。
2. またはフォルダをGitHubへアップロードして、Vercel/Netlify等で静的サイトとしてデプロイする。
3. `index.html` / `style.css` / `app.js` を同じフォルダに置く。

## ファイル構成
- `index.html` — ページ構造
- `style.css` — デザイン
- `app.js` — 店舗/レビュー/認証UIとSupabase連携
- `supabase/schema.sql` — DBテーブル・RLSポリシー
- `DEPLOY.md` — 無料公開とSupabase設定手順
- `PROJECT_SPEC.md` — 仕様書
- `COPILOT_INSTRUCTIONS.md` — Copilotなど別AIへの引き継ぎ指示

## セキュリティ
- ブラウザに置くのはSupabaseのURLとanon/public keyだけ。`service_role` キーは絶対に公開しない。
- RLSは必ず有効にし、ポリシーを確認する。
- 公開前に通報・管理者による削除/修正機能を追加することを推奨。
